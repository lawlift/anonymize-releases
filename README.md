# Lawlift Anonymize – Downloads

Installers and the update feed of **Lawlift Anonymize**, the desktop app by lawlift GmbH that
pseudonymises and redacts legal documents with a language model running on your own computer or server.

The app finds its updates here; installed apps update themselves. The source code is not published here.

| System | Download |
|---|---|
| macOS 12 or later (Apple Silicon and Intel) | `Lawlift-Anonymize-<version>.dmg` |
| Windows 10/11 (64-bit) | `Lawlift-Anonymize-<version>-Setup.exe` |
| Linux, Debian/Ubuntu | `Lawlift-Anonymize-<version>-amd64.deb` |
| Linux, other distributions | `Lawlift-Anonymize-<version>-x86_64.AppImage` |

Office model server (Linux): `install-model-server.sh` and the Compose files are attached to every release.

Product information, terms and privacy: https://www.lawlift.de · Support: anonymize@lawlift.com
